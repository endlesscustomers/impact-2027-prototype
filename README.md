# IMPACT 2027 website prototype

A clickable prototype of the two 2027 web properties, built so the team can walk the pages before anything is built for real.

- `/impactpluscom/…` stands in for **impactplus.com**, the full-service company.
- `/endlesscustomerscom/…` stands in for **endlesscustomers.com**, the system.
- The entry page lists every page on both sites and whether it is drafted or still a placeholder.

**Not indexed.** Every page carries `noindex, nofollow` and `robots.txt` disallows everything. It is viewable by anyone with the link, not private.

## Working on it

```bash
npm install
npm run dev        # http://localhost:4321/impact-2027-prototype/
npm run build      # static output in dist/
```

Live at https://endlesscustomers.github.io/impact-2027-prototype/ . Pushing to `main` deploys to GitHub Pages through `.github/workflows/deploy.yml`.

## Where things live

| What | Where |
|---|---|
| Header menus (both sites) | `src/data/impact-nav.ts`, `src/data/ec-nav.ts` |
| Every planned page and its purpose | `src/data/pages.ts` |
| A drafted page | `src/pages/impactpluscom/<path>.astro` or `src/pages/endlesscustomerscom/<path>.astro` |
| Placeholders for pages not yet drafted | generated by `[...slug].astro` in each site folder |
| Shared header, footer, page shell | `src/components/`, `src/layouts/Site.astro` |
| All CSS: tokens, type, dark mode, page primitives, page-specific rules keyed on `body[data-page]` | `src/styles/global.css` (the only stylesheet; pages have no `<style>` blocks and the build never inlines CSS) |
| How to build consistently: case rule, tokens, type, page blocks | `STYLE.md` |
| Case checker for labels and headings | `node scripts/check-copy.mjs` (`--fix` rewrites) |

To draft a page, add an `.astro` file at its path and it replaces the placeholder automatically. Links always go through `href(site, path)` from `src/lib/site.ts`, so the GitHub Pages base path is handled in one place.

This repository holds only public-safe content: copy, brand assets, fonts. Planning documents and research stay elsewhere.
